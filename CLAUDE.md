# Brasa Mind

O **Brasa Mind** é um grupo de networking (empreendedorismo, churrasco e network gaúcho).
Escreva "Brasa Mind" com duas palavras; "o Brasa" / "do Brasa" no masculino, nunca "a Brasa".
Toda copy deve reforçar o tom de conexão entre membros (conectar, indicar, fechar negócios).
Evite travessão e seta; use vírgula, dois-pontos ou parênteses. A ação vai no próprio botão.
